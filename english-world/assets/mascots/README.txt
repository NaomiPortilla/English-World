English World - expresiones de personajes

Cada personaje tiene una imagen base y cuatro expresiones recortadas que el código cambia automáticamente:
- happy: bienvenida y respuestas correctas
- think: pistas y momentos de reflexión
- celebrate: finalización de una actividad o logro
- encourage: cuando una respuesta es incorrecta, para animar a volver a intentar

Archivos incluidos: Sonic, Pikachu, Snoopy y Molang (PNG).
Las imágenes son ilustraciones de referencia generadas para este proyecto.
